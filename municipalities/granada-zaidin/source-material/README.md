# Source material — Granada-Zaidín

Expediente territorial de fuentes utilizadas por COMPÁS NG para el ámbito `granada-zaidin`.

Estructura:

- `health-reports/`: Informe de Salud fuente primaria.
- `complementary-studies/`: estudios complementarios y exports REDCap/EAS.
- `localiza-salud/`: listado de activos cargado desde Localiza Salud.
- `territorial-documents/`: informes territoriales de Zaidín Centro-Este y Zaidín Sur.
- `strategic-frameworks/`: marcos estratégicos EPVSA, ESCA y Plan de Mayores.

La línea base operativa vigente de este expediente es manual 56/92:

- 20 documentos.
- 36 evidencias de estudios.
- 56 activos Localiza Salud.
- 92 evidencias totales.
- 2 documentos territoriales.
- 3 marcos estratégicos.

El archivo `MANIFEST.json` describe qué fuentes físicas fueron encontradas, copiadas, extraídas o quedan pendientes.

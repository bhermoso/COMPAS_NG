# COMPÁS NG

Infraestructura modular para la Acción Local en Salud y la elaboración, seguimiento y evaluación de Planes Locales de Salud 2027–2030.

## Principios

- El monolito COMPÁS legacy es fuente de conocimiento, no plantilla de copia.
- Sin dependencia de window.*.
- Separación entre dominio, contratos, aplicación, persistencia, motores, interfaz e IA.
- IA como asistente, no decisora.
- Evidencia separada de interpretación.
- Trazabilidad completa.

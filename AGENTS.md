# COMPAS_NG — Repository Instructions

These instructions apply to all work in this repository.

## Canonical project instructions

For any task involving COMPAS_NG behavior, data, indicators, profiles, strategic readings, action plans, sources, local evidence, terminology or repository changes, read and follow:

`docs/COMPAS_PROJECT_INSTRUCTIONS.md`

This file contains the canonical functional and factual rules of COMPAS_NG.

## Authorial writing style

For any task that creates or changes Spanish prose in COMPAS_NG, also read and follow:

`docs/BLAS_WRITING_STYLE.md`

This applies to interface copy, report prose, methodological documentation, contracts, generated-text templates and any other product text. The style guide governs voice, syntax, paragraph construction, argumentative rhythm, lexical preferences, critical tone and avoidance of generic AI prose. It is a product constraint, not a decorative preference.

## Priority

Apply instructions in this order:

1. Explicit user instruction in the current task.
2. Verified project facts, source data and technical constraints.
3. `docs/COMPAS_PROJECT_INSTRUCTIONS.md`.
4. `docs/BLAS_WRITING_STYLE.md` whenever the task touches Spanish prose in COMPAS_NG.
5. Existing repository conventions.
6. Generic model defaults.

If style conflicts with factual accuracy, source traceability, legal requirements, technical correctness or explicit project constraints, those constraints prevail.

## Repository actions

Before changing code or content:

- inspect the relevant files;
- identify the smallest coherent change;
- preserve existing behavior unless the task requires otherwise;
- avoid duplicate sources of truth;
- verify user-visible output against the underlying data.

Do not commit, push, merge or deploy unless explicitly authorized in the current task or clearly granted by the operating context.

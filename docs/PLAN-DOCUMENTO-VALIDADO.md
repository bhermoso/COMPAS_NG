# Documento del Plan de Acción

La validación técnica explícita guarda una copia completa del contenido seleccionado en validatedActionPlans, dentro del expediente local, con fecha y persona responsable. No constituye aprobación institucional. Las descargas DOCX y PDF leen exclusivamente la última versión validada del ámbito, aunque se edite después el borrador. Sin versión validada exportan un borrador identificado. Los elementos excluidos no entran en el documento. La validación rechaza pendientes, textos modificados vacíos y referencias de borrador con versión distinta del catálogo.

El guardado confirma la escritura local antes de actualizar la interfaz. Las copias JSON del expediente incluyen las versiones. No existe sincronización remota de estas versiones. Los formatos comparten contenido; el PDF usa la tipografía estándar del exportador existente.

Los objetivos se agrupan bajo un único encabezado por bloque, siguiendo el orden del catálogo territorial. El PDF conserva juntos los títulos y el inicio de su contenido, y evita dividir los párrafos que caben en una página. El editor conserva el texto escrito exactamente; la retirada de etiquetas históricas se aplica al generar la composición.
